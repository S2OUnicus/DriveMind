# Changelog

[日本語](CHANGELOG.md) / [English](CHANGELOG.EN.md) / [中文](CHANGELOG.ZH.md) / [한국어](CHANGELOG.KR.md)

Main changes of DriveMind are recorded here.

## [v2.0.0] - Development

### Added

- Added English, Chinese, and Korean README files.
- Added English, Chinese, and Korean changelog files.
- Added Chinese and Korean license explanation files.
- Added language links to the top of README, CHANGELOG, and LICENSE files.
- Added screenshots to README files.
- Added GUI language switching.
  - Japanese
  - English
  - Chinese
  - Korean
- Added a language selector to the top-right area of the main window.
- Added language setting to **Settings > Basic**.
- Added `darkmode` / `lightmode` theme switching.
- Added a theme button to the top-right area of the main window.
- Added theme setting to **Settings > Basic**.

### Changed

- Updated the version number to `v2.0.0`.
- Rewrote README files with user-oriented operation instructions.
- Moved the **Other** menu to the right side, with the language selector and theme button placed to its left.

## [v1.3.0] - Development

- Sorted partition file-analysis categories by size, with **Other** always at the bottom.
- Added **File List** buttons to category cards.
- Added 100-item paging to file list windows.
- Added file-size sorting in file list windows.
- Adjusted file list column widths to about 70% file path and 30% size.
- Changed category items to rounded cards.
- Made only Group, Purpose, and Memo editable in the main list.
- Removed the direct “skip version” text box and added a reset button.
- Added a reset-all-settings button to **Settings > Other**.
- Added the project link to **About DriveMind**.

## [v1.2.1] - Development

- Excluded RAM disks, WebDisks, and network/remote drives by default.
- Added disk-level internal/external manual override from the disk context menu.
- Added categorized file-list opening from partition analysis.
- Added settings for read-only and hidden partitions.
- Added reset-current-tab buttons in Settings.
- Changed Purpose and Memo management to one-to-one partition management.
- Added related partition list to the Group manager.
- Added a menu bar and About dialog.

## [v1.2.0] - Development

- Added a mind map export options dialog.
- Added default export limits under Settings > Mindmap.
- Added ESP/MSR/OEM display settings.
- Added admin launch setting.
- Merged Drive and Label into one column.
- Added partition context menu and partition information dialog.

## [v1.1.0] - Development

- Moved the checkbox column to the far left.
- Changed default ordering to drive A-Z.
- Added sortable columns.
- Combined global order and per-device order into `1 - 1:1` format.
- Added background disk loading and loading indicator.

## [v1.0.0] - Development

- Added the initial DriveMind implementation with disk list, usage bars, disk information, TXT reports, DesktopNaotu `.km` export, settings, and update checking.
