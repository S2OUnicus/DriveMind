# 更新確認の使い方

DriveMind は、GitHub Releases に新しいバージョンがあるかを確認できます。

リポジトリ:

```text
https://github.com/S2OUnicus/DriveMind
```

---

## 更新確認を設定する

設定画面を開き、**その他** タブで更新確認の間隔を選びます。

選べる項目は以下です。

| 設定 | 内容 |
|---|---|
| 毎日確認 | 1 日に 1 回、新しいバージョンを確認します。 |
| 毎週確認 | 1 週間に 1 回、新しいバージョンを確認します。 |
| 毎月確認 | 1 か月に 1 回、新しいバージョンを確認します。 |
| 確認しない | 自動で更新確認を行いません。 |

初期設定では、毎日確認します。

---

## 新しいバージョンが見つかった場合

新しいバージョンが見つかると、更新通知が表示されます。

通知では、以下の操作を選べます。

### Release ページを開く

GitHub の Release ページをブラウザで開きます。  
新しいバージョンの説明、配布ファイル、更新内容を確認できます。

### 今日は提示しない

今日だけ、同じ更新通知を表示しないようにします。  
翌日以降は、設定した間隔に従って再び確認されます。

### このバージョンを提示しない

表示されたバージョンの通知を今後表示しないようにします。  
次の新しいバージョンが公開された場合は、再び通知されます。

### 閉じる

何も変更せずに通知を閉じます。

---

## 更新の実行について

DriveMind は、更新の有無を確認し、Release ページを開くところまでを行います。

以下の操作は自動では行いません。

- 更新ファイルのダウンロード
- 更新ファイルの実行
- アプリの上書きインストール

更新する場合は、Release ページの内容を確認してから、ユーザー自身で行ってください。

---

## 更新通知が表示されない場合

以下を確認してください。

- 設定画面の **その他** タブで、更新確認が「確認しない」になっていないか。
- インターネットに接続されているか。
- GitHub にアクセスできる環境か。
- 「このバージョンを提示しない」を選んでいないか。
- 今日すでに「今日は提示しない」を選んでいないか。

---

## バージョン表記

DriveMind のバージョンは、以下のように表示します。

```text
v1.0.0
v1.0.1
v1.1.0
```

GitHub Releases でも同じ形式のタグ名を使用します。
