# DriveMind

[日本語](README.md) / [English](README.EN.md) / [中文](README.ZH.md) / [한국어](README.KR.md)

![DriveMind Brand](docs/screenshots/Brand.png)

DriveMind は、Windows のディスク・パーティション情報を確認し、選択したドライブや任意フォルダの構造を DesktopNaotu 用の `.km` マインドマップとして出力するためのデスクトップアプリです。

日常的な容量確認、外部 SSD の整理、資料ドライブの棚卸し、制作プロジェクト用フォルダの可視化などに使えます。

![メイン画面](docs/screenshots/1_Index.png)

## できること

- 内部ディスク、外部ディスク、パーティションを一覧で確認
- 使用済み容量、空き容量、使用率を Progress Bar で確認
- ドライブごとに「グループ」「用途」「メモ」を記録
- グループごとに色を設定し、メイン画面のグループ列へ反映
- 選択したパーティションから DesktopNaotu 用 `.km` マインドマップを生成
- 任意フォルダをルートにしてフォルダツリーの `.km` マインドマップを生成
- 直近生成したマップ、または任意の `.km` を DesktopNaotu で開く
- ディスク情報、パーティション情報、ファイル種別分析を表示
- ファイル分析結果から分類ごとのファイルリストを確認
- 日本語、英語、中国語、韓国語の GUI 表示を切り替え
- darkmode / lightmode を切り替え
- GitHub Releases から新しいバージョンを確認
- 起動時に Brand 画像をフェードイン / フェードアウト表示

## 起動方法

開発環境で実行する場合は、プロジェクトフォルダで以下を実行します。

```powershell
python -m pip install -r requirements.txt
python -m pip install -e .
python -m drivemind
```

Windows 用 exe を作る場合の例です。

```powershell
pyinstaller --onefile --noconsole --name DriveMind --icon=src\drivemind\assets\logo_pure.ico --add-data "src\drivemind\assets;drivemind\assets" --paths src src\drivemind\__main__.py
```

生成された実行ファイルは通常 `dist\DriveMind.exe` に出力されます。

## 基本的な使い方

### 1. ディスク一覧を確認する

DriveMind を起動すると、メイン画面に検出されたディスクとパーティションが表示されます。

各パーティションには、ドライブ文字、ラベル、種類、ファイルシステム、使用状況、属性などが表示されます。

ディスク本体は選択できません。`.km` 出力対象として選択できるのは、ドライブ文字を持つパーティションです。

### 2. グループ・用途・メモを編集する

メイン画面では、以下の列だけ編集できます。

- グループ
- 用途
- メモ

グループは右クリックメニューや設定画面から管理できます。グループに色を設定すると、メイン画面のグループ列だけに背景色として表示されます。

### 3. 選択したドライブからマインドマップを生成する

1. メイン画面左側のチェックボックスで対象パーティションを選びます
2. `選択した木生成` をクリックします
3. フォルダ最大階層、同一フォルダ内の最大ファイル数などを確認します
4. 保存先を選択します
5. DesktopNaotu 用 `.km` ファイルが出力されます

初期値では、フォルダ最大階層は 48 階層、同一フォルダ内の最大ファイル数は 16 個です。サブフォルダはファイル数に含めません。

### 4. 任意フォルダからマインドマップを生成する

`フォルダ木生成` をクリックすると、任意のフォルダを選択できます。

選択したフォルダをルートとして、その中のフォルダ・ファイル構造だけを `.km` に出力します。プロジェクトフォルダや資料フォルダだけを整理したいときに便利です。

### 5. 生成したマップを開く

`木閲覧` をクリックすると、以下を選択できます。

- 最近のマップ
- 任意マップ

`最近のマップ` は、最後に生成した `.km` ファイルが存在する場合だけ選択できます。

DesktopNaotu の実行ファイルパスが未設定の場合は、最初に `DesktopNaotu.exe` を指定してください。

DriveMind は次の形式で DesktopNaotu を起動します。

```powershell
DesktopNaotu.exe DriveMind.km
```

## ディスク情報を見る

`ディスク情報` をクリックすると、総計、内部ディスク、外部ディスクごとの情報を確認できます。

容量、使用済み容量、空き容量、パーティション数、インターフェースなどをまとめて確認できます。

## パーティション情報を見る

パーティションを右クリックして `パーティション情報` を選ぶと、選択したパーティションの詳細情報を表示できます。

使用率は Doughnut Chart 形式で表示されます。ファイル分析を実行すると、ファイルを以下のように分類して容量を集計します。

- ドキュメント
- 音楽
- ビデオ
- プログラム
- その他

分類項目の `ファイルリスト` ボタンを押すと、その分類に含まれるファイル一覧を表示できます。

## 設定

`設定` から各種設定を変更できます。

### 基本設定

- 自動更新間隔
- 言語
- テーマ
- 管理者として起動するか
- RAMDisk / WebDisk / ネットワークドライブの表示
- ESP / MSR / OEM / 読み取り専用 / 隠しパーティションの表示

### DesktopNaotu

- DesktopNaotu の実行ファイルパス

### マインドマップ

- フォルダ最大階層
- 同一フォルダ内の最大ファイル数
- デバイス名を出力するか
- 隠しファイル・システムファイルの扱い
- 拡張子を出力するか
- 出力しない名前・拡張子
- プログラムフォルダも出力するか
- Adobe 系プロジェクトをフォルダだけ出力するか

### グループ

- グループの追加・削除
- グループ色の設定
- 選択したグループに属するパーティション一覧の確認

### 用途管理・メモ管理

用途とメモは、パーティションごとの一対一設定として管理します。重複する用途名やメモ内容も使用できます。

### ログ

- ログレベル
- 保留日数
- サイズ制限
- 現在のログサイズ表示
- ログを開く
- ログを全部削除

### その他

- 更新確認頻度
- バージョン提示のリセット
- すべての設定を初期化

## マインドマップ出力の補足

初期設定では、以下のような一時ファイルや管理用ファイルは出力から除外されます。

- `node_modules`
- `__pycache__`
- `_` から始まる一部フォルダ
- IDE 設定フォルダ
- `.log` ファイル
- `.tmp` ファイル
- Office 一時ファイル
- `.DS_Store`
- `Thumbs.db`
- `desktop.ini`
- `autorun.inf`

必要に応じて `設定 > マインドマップ` から変更できます。
