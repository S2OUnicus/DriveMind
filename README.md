# DriveMind

**DriveMind** は、Windows 向けのディスク情報表示・容量確認・マインドマップ生成ツールです。  
PC に接続されている内部ディスクや外部ディスクを確認し、選択したドライブのフォルダ構造を DesktopNaotu 対応の `.km` ファイルとして出力できます。

> バージョン: `v1.2.0`  
> 作者: [@S2OUnicus](https://github.com/S2OUnicus)  
> ライセンス: CC BY-NC-ND 4.0

---

## できること

DriveMind では、主に以下の操作ができます。

- 接続中のディスクとドライブを一覧表示する。
- 内部ディスクと外部ディスクを分けて確認する。
- 各ドライブの使用量、空き容量、総容量を Progress Bar で確認する。
- ドライブごとにグループ、用途、メモを設定する。
- 選択したドライブのフォルダ構造を `.km` マインドマップとして出力する。
- パーティションを右クリックして、開く・木生成・情報確認・用途編集・メモ編集を行う。
- パーティション情報画面で、使用率とファイル種類別の容量を確認する。
- 出力した `.km` ファイルを DesktopNaotu で開く。
- ディスク情報を TXT レポートとして保存する。
- GitHub Releases から新しいバージョンを確認する。

## 開発版の起動方法

Python 3.10 以上を用意し、リポジトリのフォルダで以下を実行します。

```powershell
python -m pip install -e .
python -m drivemind
```

Windows では、`scripts/run_dev.bat` または `scripts/run_dev.ps1` からも起動できます。

必要な主なPythonパッケージは以下です。

- PySide6
- psutil

```powershell
python -m pip install -r requirements.txt
```

## 基本的な使い方

### 1. DriveMind を起動する

DriveMind を起動すると、メイン画面に現在接続されているディスクとドライブが表示されます。

ドライブは物理デバイスごとにまとめて表示されます。

```text
- Samsung SSD 990 Pro（SSD、内部ドライブ、設備: 1）
  - C:  1  1:1  システム
```

表示される主な情報は以下です。

| 項目 | 内容 |
|---|---|
| チェック | マインドマップ出力対象にするかを選択します。 |
| 順番 | 全体順と設備内順を `1 - 1:1` の形式で表示します。 |
| ドライブ（ラベル） | `C: （システム）` のように、ドライブ文字とボリュームラベルをまとめて表示します。 |
| グループ | ユーザーが自由に設定できる分類です。 |
| 用途 | 例: システム、作業用、バックアップ用など。 |
| 種類 | 例: 内部 SSD、外部 HDD など。 |
| メモ | ユーザーが自由に書ける補足情報です。 |
| ファイルシステム | NTFS、exFAT などです。 |
| 使用状況 | 使用済み容量、使用率、空き容量、総容量を表示します。 |
| 属性 | 例: `RO`、`H`、`OEM`、`NL`、`VSS` など。 |

列の順番は、使いやすいように調整できます。

また、以下の列名をクリックすると表示順を変更できます。

- 順番
- ドライブ
- グループ
- 種類
- 使用状況

初期表示は、ドライブ名の A-Z 順です。もう一度同じ列名をクリックすると、昇順・降順を切り替えます。

---

### 2. ドライブ情報を更新する

ドライブ情報は、初期設定では一定間隔で自動更新されます。  
すぐに最新状態を確認したい場合は、**更新** ボタンを押します。

外部ドライブを接続した直後や取り外した直後は、更新ボタンを押すと状態を確認しやすくなります。

ディスク情報の読み込み中は、画面中央に読み込み表示が出ます。読み込み中でもウィンドウが固まりにくいよう、取得処理はバックグラウンドで行います。

---

### 3. ディスク情報を見る

**情報** ボタンを押すと、ディスク情報ウィンドウを開きます。

この画面では、総計、内部ディスク、外部ディスクごとに情報を確認できます。

確認できる内容の例:

- ディスク名
- 設備順番
- 内部ディスク / 外部ディスクの区分
- SSD / HDD などの種類
- インターフェース
- パーティション数
- 使用状況
- UUID などの識別情報
- S.M.A.R.T 情報

必要に応じて、情報を TXT レポートとして保存できます。

---

### 4. マインドマップを生成する

1. メイン画面で、出力したいドライブにチェックを入れます。
2. **木生成** ボタンを押します。
3. 出力前の設定パネルで、フォルダ最大階層と同一フォルダ内の最大ファイル数を確認します。
4. 保存先を選択します。
5. DesktopNaotu 対応の `.km` ファイルが生成されます。

初期値では、フォルダ階層は最大 48 階層、同一フォルダ内のファイル出力は最大 16 個までです。サブフォルダはこのファイル数には含まれません。

出力されるマインドマップの基本構造は以下です。

```text
- 属性: 設備名
  - ドライブ文字: ラベル
    - フォルダ
      - サブフォルダ
```

例:

```text
- 内部 SSD: Samsung 990 Pro
  - C: システム
    - Program Files
    - Users
    - Windows
```

---

### 5. 生成したマインドマップを開く

**木閲覧** ボタンを押すと、生成した `.km` ファイルを DesktopNaotu で開きます。

初回利用時、または DesktopNaotu の場所が未設定の場合は、DesktopNaotu の実行ファイルを選択してください。選択したパスは設定に保存されます。

別の `.km` ファイルを開きたい場合は、木閲覧ボタンの長押し操作からファイルを選択できます。

## パーティションの右クリック操作

メイン画面のパーティション行を右クリックすると、以下の操作ができます。

| 操作 | 内容 |
|---|---|
| パーティションを開く | エクスプローラーで対象パーティションを開きます。 |
| このパーティションの木を生成する | 右クリックしたパーティションだけを `.km` に出力します。 |
| グループ変更 | 既存グループの選択、または新規入力を行います。 |
| パーティション情報 | 所属デバイス、容量、属性などをまとめて表示します。 |
| 用途編集 | 用途を編集します。 |
| メモ編集 | メモを編集します。 |

パーティション情報画面では、使用率を円形表示で確認できます。
**ファイル分析** を押すと、ドキュメント、音楽、ビデオ、プログラム、その他に分けて容量を集計します。

## 使用状況 Bar の見方

使用状況 Bar では、ドライブ容量を以下の形式で表示します。

```text
[使用済み容量] [使用率] [空き容量] [総容量]
```

表示例:

```text
4.00 GB        40.00 %        6.00 GB        10.00 GB
```

容量単位は MB、GB、TB などから自動で選ばれます。  
小数点以下の桁数は、設定画面から変更できます。

空き容量の割合によって、Bar の色が変わります。

| 空き容量 | 色の目安 |
|---:|---|
| 50%以上 | 浅い緑 |
| 25%以上 50%未満 | 浅い黄色 |
| 12%以上 25%未満 | 浅い赤 |
| 12%未満 | 浅い紫 |

## 設定

**設定** ボタンから、DriveMind の動作を変更できます。

設定画面には、以下のタブがあります。

| タブ | 内容 |
|---|---|
| 基本設定 | 自動更新間隔、特殊パーティション表示、管理者起動、設定保存先、自動保存などを設定します。 |
| DesktopNaotu | DesktopNaotu の実行ファイルパスを設定します。 |
| マインドマップ | `.km` 出力時のフォルダ・ファイル名の扱いを設定します。 |
| グループ | グループ名と表示色を管理します。 |
| 用途管理 | 用途の候補を管理します。 |
| メモ管理 | メモの候補を管理します。 |
| その他 | 更新確認などの補助機能を設定します。 |

---

## マインドマップ出力設定

マインドマップ出力では、以下のような項目を設定できます。

- 隠しファイルや隠しフォルダを出力するか。
- 隠し項目の末尾に ` [Hide]` を付けるか。
- システムファイルを出力するか。
- 拡張子を出力するか。
- フォルダ最大階層の初期値。
- 同一フォルダ内の最大ファイル数の初期値。
- `System Volume Information` や `$MFT` などを出力から除外するか。

初期設定では、隠しファイルや隠しフォルダは出力され、名前の末尾に ` [Hide]` が付きます。

## 更新確認

DriveMind は GitHub Releases を確認し、新しいバージョンがある場合に通知できます。

更新確認の間隔は、設定画面の **その他** タブで変更できます。

- 毎日確認
- 毎週確認
- 毎月確認
- 確認しない

新しいバージョンが見つかった場合、更新通知には以下の操作が表示されます。

| ボタン | 動作 |
|---|---|
| Release ページを開く | GitHub のリリースページを開きます。 |
| 今日は提示しない | 今日だけ同じ通知を表示しません。 |
| このバージョンを提示しない | 指定したバージョンの通知を今後表示しません。 |
| 閉じる | 通知を閉じます。 |

DriveMind は Release ページを開くだけで、更新ファイルの自動ダウンロードや自動インストールは行いません。

## 設定ファイル

設定はローカルに保存されます。

初期保存先:

```text
Config/<computer-id>.txt
```

`<computer-id>` は、PC を区別するための 16 文字の識別子です。  
DriveMind を別の PC に移動した場合でも、使える設定項目はそのまま利用できます。

## DesktopNaotu について

DriveMind は `.km` ファイルを生成しますが、DesktopNaotu 本体は同梱しません。  
マインドマップを開くには、DesktopNaotu を別途用意してください。

DesktopNaotu:

```text
https://github.com/naotu/desktopnaotu
```
